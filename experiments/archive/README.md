# Archived development runs

These checkpoints and logs preserve earlier iterations and quick pipeline experiments. They are retained as project history, not as current policy recommendations. The current reference run is `../../trained-v4/`.

- `trained-v2/`, `trained-v3/`, `checkpoints/`, and `trained/` were generated before the current assisted-grasp simulator changes and had poor held-out robustness.
- `bc-reach/` records a small behavior-cloning reach experiment.
- `bootstrap-smoke/` and `smoke-run/` are pipeline checks with very few SAC steps.

The archived runs contain model checkpoints and their JSONL/JSON evaluation logs. Python environments and temporary debug images were not copied.
