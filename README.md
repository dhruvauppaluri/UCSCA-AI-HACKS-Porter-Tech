# RoboArm — voice-guided robot drawing

An SO-101 follower drawing project built from recorded leader/follower demonstrations, calibrated pen-tip kinematics, trajectory smoothing, MuJoCo experiments, and an ElevenLabs voice-feedback interface.

**Current focus: drawing on paper.** Updated October 11, 2026. The earlier pick-and-place project remains available in the [historical guide](LEGACY_PICK_AND_PLACE.md).

## What works today

| Component | Evidence and current scope |
|---|---|
| Physical demonstration capture | Recorded leader actions, follower joint positions, and sent commands at about 30 Hz. |
| Physical 9 | A demonstration-derived, reshaped loop was executed and described by the operator as “basically perfect(ish).” The saved routine shortens its stem; that shortened variant has not been physically retested. |
| Physical smiley face | Two eye dots and a smile curve were executed; a second version increased modeled pen lift from 20 to 40 mm. The operator selected that version to preserve. |
| Return to rest | Both saved routines include a smooth return to the session's saved resting pose, leaving torque enabled. |
| Z predictor | Fitted across seven paired recordings, with held-out evaluations and stress tests. This is an offline prediction model, not an online XYZ correction controller. |
| MuJoCo drawing | Recorded-path and generated-text/shape simulations, with rendered scenes, ink comparisons, and videos. Simulated agreement is not measured physical writing accuracy. |
| Voice feedback | Implemented client tools, persistent run ratings, preferred revisions, and bounded correction generation. Offline tests pass; live ElevenLabs-to-robot integration has not been verified. |

## How the drawing workflow fits together

1. Teleoperate a drawing and record measured follower motion alongside leader targets.
2. Convert joints to estimated pen coordinates using the calibrated geometric model.
3. Smooth the demonstration or impose a requested shape, such as two dots and a symmetric smile.
4. Solve pen-tip inverse kinematics to produce six-channel joint-command CSVs.
5. Execute with calibration, serial ownership, torque, timing, and tracking checks; log observations.
6. Use the operator's feedback to prepare a revised candidate and retain approved versions.

The deployed drawing routines use generated joint targets. The learned Z predictor is evaluated separately; it is not silently applied during physical playback. Model coordinates and servo tracking do not directly measure ink position or pen pressure.

## Voice and feedback

“Draw a smiley” selects a saved routine. After a completed physical run, the agent asks for feedback. Approval records +1 and selects the exact revision; rejection records −1 and allows a correction proposal. Supported adjustments are lift height, 9 stem length, smile depth, and eye spacing. A candidate is executed when the user requests a test.

This is human-feedback adaptation with persistent preferences. It is not a trained reinforcement-learning policy, and it does not execute arbitrary code generated by a language model.

From a Python environment with NumPy, run the offline workflow tests:

```bash
python -m pip install numpy
python -m unittest discover -s voice/feedback -p 'test_*.py'
```

For microphone dry runs, install `elevenlabs[pyaudio]`, set `ELEVENLABS_API_KEY` and `ELEVENLABS_AGENT_ID`, configure the five client tools, then run:

```bash
python voice/feedback/elevenlabs_bridge.py
```

This defaults to **no robot movement**. Physical mode requires the configured LeRobot station and its serial devices, calibration, helper scripts, pen mount, and paper layout. See the [full setup](voice/feedback/README.md) before using `--physical`. A separate laptop-to-station voice transport is not implemented.

## Setup and units

- Paper: **220 × 275 mm**; captured inset drawing rectangle: **170 × 235 mm**.
- Physical body-joint commands: degrees; gripper: calibrated percentage. MuJoCo joints use radians.
- Drawing waypoints: paper coordinates in millimeters. Predictor inputs use the robot base frame; these frames are not interchangeable.
- Pen protrusion was approximately 1.5 inches; fitted tip and paper transforms remain approximate.
- Saved routines depend on the same physical arrangement and the session's calibration. A 40 mm modeled lift is not a measured 40 mm tip clearance.

## Known limits

Physical drawing quality is currently judged by operator feedback. Pen pressure is not measured. Geometry fitting has millimeter-scale errors, and sparse-sample Z stress testing exposed a large pointwise miss (126.7 mm). Neither small internal IK residuals nor successful command completion prove real ink accuracy. New geometry/contact changes remain candidates until physically evaluated.
